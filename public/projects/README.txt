Put your project screenshots in this folder, then point to them in src/data.ts:

  image: '/projects/aksverse.png',

Tips:
- Use PNG, JPG or WebP. A landscape screenshot works best (about 1600 x 1000 px).
- Keep each file under ~300 KB so the page stays fast.
- File names are case-sensitive on GitHub Pages: "Buyit.png" is not "buyit.png".
