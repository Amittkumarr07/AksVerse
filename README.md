# AksVerse

Personal portfolio of Amit Kumar, built with plain HTML, CSS and JavaScript (no frameworks).

**Live site:** https://theamitkumar.in

## Features

- Dark and light theme with a saved preference
- Animated loader and particle-network background
- Typing effect, scroll-reveal animation (plays once) and active-section navigation
- Mobile layout with a bottom dock and swipeable project cards

## Structure

```
index.html
css/   styles.css, aksverse-loader.css
js/    script.js, aksverse-loader.js, particle-network.js, site-background.js
images/projects/   project screenshots
```

Open `index.html` in a browser to run it locally.
